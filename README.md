# FlowGuard Plumbing Website

A modern, customer-focused plumbing business website inspired by Centerline Plumbing and O'Hare Plumbing, with a unique navy/teal design.

## Features

- 24/7 emergency call bar
- Hero with callback form and trust stats
- Service grid (residential + commercial)
- Why choose us section with social proof
- 4-step process overview
- Customer reviews
- FAQ accordion
- Contact form with business details
- Fully responsive (mobile-first)
- Smooth scroll animations

## View Locally

Open `index.html` in your browser, or run a local server:

```bash
cd flowguard-plumbing
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080)

## Customize

- Update phone, email, and address in `index.html`
- Adjust colors in `css/styles.css` (`:root` variables)
- Replace placeholder testimonials with real reviews
